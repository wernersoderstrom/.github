# Werner Söderström Ltd

## English

Werner Söderström is one of Finland’s leading publishing houses. This GitHub organization hosts software packages developed for our internal needs that we have chosen to release as open source, making them available for the wider community to use, contribute to, and build upon.

## Suomeksi

Werner Söderström on yksi Suomen johtavista kustantamoista. Tämä GitHub-organisaatio sisältää omaan sisäiseen käyttöömme kehitettyjä ohjelmistopaketteja, jotka olemme päättäneet julkaista avoimena lähdekoodina myös muiden hyödynnettäviksi, kehitettäviksi ja jatkojalostettaviksi.
